## Requisitos para compilar

Este proyecto utiliza Qt (versión 6.11.1), que se puede encontrar en el siguiente enlace: https://doc.qt.io/qt-6/get-and-install-qt.html.

Dentro de Qt, se hace uso de los siguientes módulos: Core, Widgets, OpenGL, OpenGL Widgets. Al instalar Qt, hay que asegurarse de seleccionar el kit correspondiente a MSVC 2022 64-bit.

Para compilarlo se requiere Visual Studio 2022, con la carga de trabajo "Desarrollo para el escritorio con C++" instalada, además de la extensión "Qt VS Tools", necesaria para que Visual Studio reconozca la instalación de Qt.
